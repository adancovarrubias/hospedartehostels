# Hospedarte Hostels

Modern website for Hospedarte Hostels featuring an integrated BarHop Adventures tours section.

## 🌟 Overview

This is a complete modern redesign of hospedartehostels.com, featuring:
- Main hostel website with rooms, amenities, and booking information
- Integrated BarHop Adventures tours section for nightlife experiences
- Fully responsive design optimized for all devices
- Modern UI/UX with smooth animations and interactions

## 🚀 Features

### Main Hostel Website
- **Hero Section**: Eye-catching gradient background with clear CTAs
- **About Section**: Statistics counter showcasing key metrics
- **Rooms**: Three accommodation types (Shared Dorm, Private Room, Family Suite)
- **Amenities**: WiFi, Kitchen, Laundry, Common Area, Security, Breakfast
- **Testimonials**: Customer reviews from international guests
- **Contact**: Form with validation and social media links
- **Newsletter**: Email subscription in footer

### BarHop Adventures Integration
- **Positioned as**: "Experiencia Adicional" for hostel guests
- **Tours Offered**: 
  - Classic BarHop ($25) - Historic center bars
  - Craft Beer Tour ($30) - Local breweries
  - Rooftop Experience ($35) - Best city views
- **Features**: 
  - Nightlife tours (4-5 bars per night)
  - Drinks included (first drink at each venue)
  - Small groups (max 15 people)
  - Local expert guides
- **Special Offer**: 15% discount for hostel guests

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Web server (for local development)

### Running Locally

1. Clone the repository
```bash
git clone https://github.com/adancovarrubias/hospedartehostels.git
cd hospedartehostels
```

2. Start a local web server
```bash
# Using Python 3
python3 -m http.server 8000

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8000
```

3. Open in browser
```
http://localhost:8000
```
